# Fase 1 · Técnicas de UX y prototipado

## Ficha de User Persona

| Campo | Contenido |
|---|---|
| Nombre / rol | Jasiel Rubio · Ingeniero Senior DevOps / Cloud Architect |
| Metas | Diagnosticar caídas de servicios en segundos; monitorear CPU, RAM y ancho de banda en tiempo real; desplegar o reiniciar instancias cloud de forma rápida y segura |
| Frustraciones | Interfaces sobrecargadas con poca jerarquía visual; falta de confirmación clara en acciones críticas que provocan reinicios accidentales; mala adaptabilidad en móviles durante guardias (on-call) |

## Wireframes

| Escritorio | Móvil |
